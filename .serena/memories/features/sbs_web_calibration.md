# Удалённая веб-калибровка SBS

- Встроенный прототипный LAN HTTP-сервер запускается на уровне процесса через `MoonlightApplication`, только если `checkbox_enable_sbs_calibration_server=true`; Foreground Service нет, default выключен. TCP port и статус/URL находятся в Android streaming settings.
- `SbsCalibrationServer` владеет блокирующим `ServerSocket`, HTTP API и asset `app/src/main/assets/sbs_calibration.html`. Без клиента сервер блокируется в `accept()` и не poll-ит. Авторизация/TLS/mDNS намеренно отсутствуют.
- `SbsCalibrationController` владеет live/saved state. Render thread читает один immutable `SbsCalibrationSnapshot` через atomic reference; preview не пишет preferences, Save сохраняет целый snapshot, Revert возвращает saved, Reset только preview-ит safe defaults до Save.
- `PreferenceConfiguration` владеет persisted keys/defaults. Старые scale/separation/vertical keys сохранены; Lens X/Y имеют отдельные `0..100%` значения и enable-флаги. Legacy lens scalar при старте переносится в обе включённые оси и удаляется, чтобы native Android UI и runtime совпадали. Offsets, yaw/pitch corrections и common horizontal offset по умолчанию нулевые. Chromatic X/Y имеют отдельные signed значения и enable-флаги; legacy scalar key читается как одинаковое значение обеих включённых осей и удаляется при следующем Save. Common horizontal складывается с per-eye offset и сдвигает уже настроенную пару без изменения разницы глаз. Head tracking сохраняет master, независимые X/Y enable/sensitivity и общий `edge reach 0..100%` с default 100%.
- `SbsRenderer` применяет snapshot в существующем OES GLES2 pass: full eye viewport, inverse perspective homography для yaw/pitch, radial inverse lookup вокруг фиксированного физического центра линзы и опциональную chromatic correction. Scale считается от aspect-preserving cover-размера: при 100% кадр полностью покрывает каждый eye viewport без растяжения, а обрезанная часть доступна head-controlled viewport; меньшие значения являются долей cover-размера. Lens и chromatic используют отдельные `vec2` coefficients для независимого X/Y displacement; выключенная ось получает ноль. Когда обе effective chromatic components равны нулю, остаётся один texture sample; иначе R/G/B берутся из трёх разнесённых координат, green является опорным. `SbsHeadTracker` владеет отдельным sensor thread, game rotation vector с fallback, относительной позой и baseline recenter; `Game` запускает/останавливает его вместе с активным SBS renderer. Sensor-only redraw повторно использует последнюю OES texture без лишнего `updateTexImage()`. Вертикальное движение изображения совпадает по знаку с pitch головы. Edge reach задаёт clamp движения: 0% не допускает дополнительного выхода за границу контента, 100% позволяет довести край изображения до центра линзы. Новых texture/FBO/pass, CPU frame copies и изменений decoder/Surface lifecycle нет. Direct-to-Surface normal mode не затронут.
- HTTP API: `GET /api/state`, `POST /api/preview`, `/api/save`, `/api/revert`, `/api/reset`, `/api/recenter`; form-urlencoded body, JSON snapshot response. Slider UI debounce/abort-ит промежуточные preview. Head-controlled viewport имеет master enable, независимые enable/sensitivity X/Y, общий Edge reach и runtime-only `Center view`; recenter не сохраняет и не сбрасывает параметры картинок.
- Unit tests находятся в `app/src/test/java/com/limelight/{preferences,binding/video}` и покрывают defaults/clamp, map round-trip/legacy scalar migration, сохранение head-tracking master/X/Y/edge-reach settings, common+per-eye sums, common horizontal pair translation, per-axis lens/chromatic disable/coefficient mapping, HTTP parsing/JSON fields, identity homography, landscape mapping rotation-vector axes, cover-scale, vertical direction и sensitivity/edge clamp динамического сдвига.
- Полная runtime-проверка требует device smoke: normal/SBS, live sliders, Save/Revert/Reset, connect/disconnect, background/foreground, Surface recreation, 1440p60 HEVC, orientation/aspect и latency.
